# D0 Reserved Keywords 0.1

| Keyword | Meaning |
|---|---|
| `fn` | Function declaration |
| `module` | Module declaration |
| `let` | Immutable binding |
| `mut` | Mutable binding |
| `if` | Conditional |
| `else` | Alternative branch |
| `while` | While loop |
| `for` | For loop |
| `in` | Range/iterator membership |
| `return` | Return from function |
| `true` | Boolean true |
| `false` | Boolean false |
| `struct` | Planned structure declaration |
| `trait` | Planned trait declaration |
| `import` | Planned module import |
| `pub` | Planned public visibility |

`struct`, `trait`, `import` and `pub` are reserved for planned features; they are not necessarily accepted by the first interpreter milestone.

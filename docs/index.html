Quick Start

Clone, build, and check your first D0 program in seconds:

# 1. Clone D0 repository
git clone https://github.com/Dinesh0729/d0.git
cd d0

# 2. Build compiler frontend (d0c)
cargo build --release

# 3. Check syntax and types
cargo run -- check examples/valid_program.d0

# 4. View AST structure
cargo run -- parse examples/hello.d0
